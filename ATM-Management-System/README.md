## 📌 Description

A menu-driven ATM Management System developed using Python.

This project simulates basic ATM operations and allows users to perform simple banking transactions through a command-line interface.

---

## ✨ Features

- ✅ Check Balance
- ✅ Deposit Money
- ✅ Withdraw Money
- ✅ Insufficient Balance Validation
- ✅ Exit the System

---

## 🛠️ Concepts Used

- Variables
- User Input (`input()`)
- While Loop
- If-Elif-Else Statements
- Arithmetic Operators
- Program State Management
- Conditional Logic
